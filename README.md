# Vinayaka Haven

Build a Premium Animated Website for Sri Vinayaka Boys Hostel

Create a premium, clean, modern, illustrative and highly animated responsive website for a boys' hostel called “Sri Vinayaka Boys Hostel”, located in South Kamala Nagar, ECIL, Moula Ali, Hyderabad, Telangana – 500062.

The website should feel like a combination of a premium student residence + comfortable home + modern co-living space.

Do NOT make it look like a generic hostel template.

The overall design should communicate:

Comfort

Safety

Cleanliness

Homely atmosphere

Good food

Wi-Fi connectivity

Study-friendly environment

Security

Convenience

Trust

Affordable premium living

1. DESIGN DIRECTION

Visual Style

Use a:

Premium + Minimal + Illustrative + Modern + Warm + Clean

design language.

Avoid:

Overly colorful layouts

Cheap-looking gradients

Excessive glassmorphism

Too many cards

Heavy shadows

Generic stock-template appearance

Excessive animations

Cluttered sections

The website should look like a professionally designed hospitality/co-living website.

Think:

Modern student residence + boutique hotel + premium co-living website.

2. COLOR PALETTE

Use a sophisticated warm palette.

Primary:

Deep Navy / Charcoal: #101820

Warm Cream: #F8F5EF

Off White: #FFFDF8

Terracotta / Warm Orange: #C86B3C

Soft Gold: #D7A84B

Use the colors consistently.

The background should mostly be:

Warm cream

Very light beige

Use dark navy/charcoal for headings and text.

Use terracotta/gold only as accent colors.

Strong visual hierarchy
